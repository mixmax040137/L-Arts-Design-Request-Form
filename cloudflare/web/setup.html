เชื่อมกับ Apps Script และย้ายข้อมูล

ใส่ลิงก์เว็บแอปของ Apps Script (ลงท้าย /exec) และบัญชีผู้ดูแลระบบเดิม ระบบจะคัดลอกข้อมูลทั้งหมดมาไว้ที่นี่ แล้ว Apps Script จะเปลี่ยนเป็นระบบสำรองที่ส่งลิงก์เดิมมาที่นี่ให้เอง (ต้องอัปเดตโค้ด Apps Script เป็นรุ่นที่มีไฟล์ 15_Bridge ก่อน)

ตรวจข้อมูลสำรอง

ใช้บัญชีผู้ดูแลระบบ "ตรวจเทียบ" ดูว่าข้อมูลสองฝั่งตรงกันทุกชีต ถ้าไม่ตรง (เช่น มีคนแก้ใน Google Sheets เอง) กด "ส่งข้อมูลทั้งหมดไปสำรองใหม่" เพื่อเขียนทับฝั่ง Apps Script ด้วยข้อมูลของระบบหลัก
